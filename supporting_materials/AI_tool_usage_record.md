# AI 工具使用记录

| 工具 | 使用环节 | 主要用途 | 人工核验方式 |
|---|---|---|---|
| OpenAI Codex | 论文写作与排版 | 辅助润色中文表述，检查 LaTeX 章节组织、交叉引用和排版问题 | 参赛队员逐段复核正文，并通过 XeLaTeX 编译和 PDF 页面检查确认 |
| OpenAI Codex | 程序开发 | 辅助检查 Python 代码结构、报错信息及可复现性 | 参赛队员审阅代码，独立运行程序，并将输出与正文、图表和结果表交叉核对 |
| OpenAI Codex | 模型表达检查 | 辅助检查符号、公式、约束和算法文字是否一致 | 参赛队员依据题目条件、推导过程与最终计算结果逐项核验 |

说明：AI 工具仅用于辅助表达、调试和检查。模型选择、参数设定、结果判断及最终提交内容均由参赛队员负责。
