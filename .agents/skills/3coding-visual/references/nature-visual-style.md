# Nature 风格科研绘图规范

本规范提炼现有科研图模板的共同技巧：信息优先、克制配色、字体统一、图层有序、紧凑导出。

## 图型选择

每张图只回答一个主要问题。比较使用点图、区间图或坡度图；分布使用箱线/小提琴/雨云图并尽量保留原始点；预测使用真实值—预测值、1:1 基准线、残差或边缘分布；性能使用交叉验证曲线、均值和置信带；多指标优先小倍图或标准化热力图。

## 版式、字体与线条

- 单栏约 85 mm，通栏约 170–180 mm，按最终插入尺寸设计。
- 简单图优先 4:3 或近方形；多面板共用坐标与图例，左上角标 `(a)`, `(b)` 并对齐绘图区。
- 用 `constrained_layout=True` 或 `GridSpec`；导出设置 `bbox_inches="tight"`、`pad_inches=0.02–0.08`。
- 中文用思源或系统中文字体；英文数字用 Arial/Helvetica；数学用 STIX/Times。
- `pdf.fonttype=42`，`svg.fonttype="none"`。最终尺寸下刻度 7–9 pt、轴标签 9–11 pt、面板标签 10–12 pt。
- 坐标轴 0.8–1.2 pt，主数据线 1.5–2.2 pt，辅助线 0.6–1.0 pt；网格只用浅灰细线。

## 配色和图层

- 使用 2–5 个低饱和、色盲友好颜色；一个主强调色，其余弱化。
- 同一变量/方案跨图固定颜色；同时使用线型、点型或直接标注，不能只依赖颜色。
- 填充透明度通常 0.12–0.35；置信区间在曲线下，原始点在统计摘要上。
- 连续值才用连续色图；正负值用以零为中心的发散色图；禁止 `jet` 和彩虹色。

推荐起点：`#3B6FB6`, `#3A8F7B`, `#B46A55`, `#7A6FA8`, `#777777`。

## 数据与复核

说明样本量、误差和区间含义；散点重叠用透明、抖动、空心点或密度处理；说明对数轴、截断轴、归一化和异常处理；只注释关键阈值、最优点和转折。保存作图数据和随机种子，以最终尺寸和灰度预览检查标签、单位、图例、色条、字体嵌入、透明度与裁剪。
